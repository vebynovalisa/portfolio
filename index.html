About

A bit about me

I got into AI because I like seeing a messy pile of data turn into something that can actually make a prediction. I enjoy figuring out which data matters, how to prepare it, and which model best fits the problem.

I don’t like leaving a model sitting in a notebook, so whenever I can, I wrap it in a simple web app that someone without a technical background can try. So far, I’ve worked with tabular data, images, and text, and I continue to learn and grow with every project.

  • Data Preparation

    Cleaning, exploring, and shaping raw data for models to learn from.

  • Model Building

    Training and evaluating models for tabular data, images, and text.

  • Web Deployment

    Deploying models as simple web apps with Flask, FastAPI, and Vercel.
